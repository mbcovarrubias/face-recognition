# face-recognition
WIP, some features may not work yet

## How to set up
1. download node.js and XAMPP if don't have
2. in XAMPP start the MySQL module
3. download and extract this repository anywhere. it's recommended to extract it in your username's directory.
4. open any shell (cmd, powershell, etc.) and change directory to "face-recognition" by typing "cd face-recognition".
5. install nodemon
6. type "node hardReset.js" in the shell you are using. this will ensure that the system works properly, especially when handling databases.
7. to start the system, type "npm run start" or "npm start"
8. in a web browser, type **localhost:[port number]** on the search bar. the server.js file uses **3000** as the port number.
